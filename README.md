# 🧠 AI Brain Tumor Detector - 15mm Auto-Detection

Built in Kete-Krachi, Oti Region, Ghana 🇬🇭 by SEKYIOT

An AI that detects 15mm brain tumors from MRI scans using Python.

### 🎯 What it does
- Takes MRI scan (real_brain_mri.png)
- Finds white region = tumor
- Draws red bounding box + calculates 15mm size
- Saves ai_tumor_detected.png

### 🛠️ Tech Stack
- Python 3.14
- NumPy, Matplotlib, Pillow
- Works offline - perfect for Ghana hospitals

### 📸 Results
- Input: real_brain_mri.png (22.2 KB)
- Output: ai_tumor_detected.png - 15mm tumor marked

### ▶️ How to run
pip install numpy matplotlib pillow
python main.py

### 🌍 Vision
To help doctors in Oti Region detect tumors faster with AI.
